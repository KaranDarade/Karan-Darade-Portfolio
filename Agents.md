# Project Instructions

## Obsidian Knowledge Vault

The `/vault` directory is the central knowledge base for this project.

The vault is opened and managed using Obsidian.

Use the vault to store and maintain important project knowledge, including:

- Feature specifications
- Architecture documentation
- Technical decisions
- Research
- Testing requirements
- Security considerations

## Working With The Vault

Before implementing a significant feature:

1. Check the relevant documentation in `/vault`.
2. Check existing specifications before creating new ones.
3. Check architecture and previous technical decisions.
4. Update the relevant vault documentation when important project knowledge changes.

Do not rely only on conversation memory for important project information.

Keep important project knowledge in the `/vault` directory.
